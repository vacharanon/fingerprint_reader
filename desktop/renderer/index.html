Fingerprint Reader

Use your Mac’s Touch ID to enroll or verify with the fingerprint reader system.

✋

Enroll Fingerprint

Enter a slot ID (1–127) and authenticate with Touch ID to link your fingerprint to that slot.

The slot ID must match the ID used on the Arduino/ESP32 device (1–127).

🔓

Verify Fingerprint

Enter your slot ID and authenticate with Touch ID to verify your identity with the reader system.

Authenticate with the same fingerprint used during enrollment to notify the server of a successful verification.
